# 开场动画（Splash Screen）设计

**项目**：当妹卡降临到我身边（原"牌佬的奇妙冒险"）
**日期**：2026-08-06
**状态**：已确认

---

## 目标

在应用加载后，先播放一段 ~1.8s 的开场动画，动画结束后过渡到首页（标题界面 + 封面轮播）。

当前问题：封面轮播和标题界面同时出现，缺乏开场仪式感。

---

## 动画分镜（光之涟漪）

| 阶段 | 时间 | 画面 |
|------|------|------|
| 黑暗 | 0-0.2s | 全屏纯黑 `#0a0d14` |
| 光点亮起 | 0.2-0.5s | 屏幕正中央，一颗灵蓝色 `#4FC3F7` 光点浮现并脉动变大 |
| 光之涟漪 | 0.5-1.0s | 光点向外扩散出 3 圈同心光涟漪（半透明蓝），一圈接一圈荡开，呼应"回响" |
| 标题浮现 | 1.0-1.4s | 涟漪消散时，标题"当妹卡降临到我身边"以暖金色 `#FFD54F` 从光晕中心浮现，带 glow 光晕 |
| 停留 | 1.4-1.6s | 标题完整呈现，光晕微微呼吸 |
| 淡出 | 1.6-1.8s | 整屏 fade out → 露出首页 |

---

## 技术方案

- **CSS**：光点脉动（`@keyframes pulse`）、涟漪扩散（`@keyframes ripple` 用 border + opacity 模拟）、文字 fadeInUp（`@keyframes fadeInUp`）、整屏淡出（`transition: opacity`）
- **JS**：~20 行，在 `app.js` init 最前面创建 splash overlay → 监听 `animationend` 或 `setTimeout` → fade out → remove DOM → 继续正常 init 流程
- **HTML**：不改动现有结构，splash 由 JS 动态创建
- **文件变更**：
  - 新增 `css/splash.css`
  - 修改 `js/app.js`（在 init 开头插入 splash 逻辑）
  - 修改 `index.html`（引入 splash.css）
  - 修改 `js/title.js`（标题文字从"牌佬的奇妙冒险" → "当妹卡降临到我身边"）

---

## 不影响

- 封面轮播（`#cover-slideshow`）保持不变
- 标题界面的按钮逻辑不变
- 粒子 Canvas 不变
- AI 桥接、设置、导航等其他模块不变

---

## 验收标准

1. 页面加载后先看到纯黑屏 → 光点 → 涟漪 → 标题浮现 → 淡出 → 首页
2. 总时长约 1.8s，动画流畅不卡顿
3. 首页显示后，标题文字为"当妹卡降临到我身边"
4. 有存档时跳过 splash，直接进入事件视图（与现有逻辑一致）
