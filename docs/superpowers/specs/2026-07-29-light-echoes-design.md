# 设计文档：光之回响 — 文字冒险 × 卡牌对战 Web 前端原型

**日期：** 2026-07-29
**状态：** 已批准
**类型：** 前端原型（无后端）

---

## 1. 项目概述

### 1.1 核心概念

一款以 Ori 空灵森林美学为视觉基调的文字冒险 + 卡牌对战游戏 Web 前端原型。玩家在叙事驱动的世界中探索，通过文字交互推进故事，以《游戏王：大师决斗》风格的卡牌对战解决冲突。

### 1.2 美学方向

- **参考来源：** Ori and the Blind Forest / Ori and the Will of the Wisps
- **视觉基调：** 空灵、发光、手绘感、深色背景 + 辉光粒子
- **色彩体系：**
  - 主色调：灵火蓝（#4FC3F7）、Spirit Green（#81C784）
  - 点缀：暖金辉（#FFD54F）
  - 对战场景：蓝紫 vs 暗红对立色
  - 稀有度色：灰（普通）、蓝（稀有）、紫（史诗）、金（传说）
- **字体：** 霞鹜文楷（正文，手写感）、思源黑体（UI 标签）、Cinzel（英文标题）、Inter（英文正文）
- **图标库：** Lucide Icons（SVG，轻量专业）
- **禁止：** emoji、浏览器默认字体、浏览器原生 alert/confirm

### 1.3 技术方案

| 决策 | 选择 |
|------|------|
| 框架 | 纯 HTML/CSS/JS（单页 SPA） |
| 状态管理 | 集中式 JS 状态对象 + 事件驱动更新 |
| 数据持久化 | localStorage（存档/卡组/设置） |
| 粒子效果 | CSS 动画为主 + Canvas（仅战斗大招） |
| 构建工具 | 无，原生 ES 模块 |
| 性能 | CSS GPU 加速、卡牌虚拟化渲染、标签懒加载 |

## 3. 各界面详细设计

### 3.1 标题界面

- 深色背景上漂浮发光粒子
- 手写体中文标题（"光之回响"）微微浮动
- 三个选项按钮：继续冒险（读 localStorage）/ 新的旅程（开场叙事→第一个事件）/ 设置
- 设置面板：文本速度（慢/正常/快）、动画强度（简约/标准/华丽）、音量滑块、卡牌动画速度

### 3.2 事件对话界面（主界面）

```
┌──────────────────────────────────┐
│  [场景氛围背景 — 半透明渐变层]    │
│                                  │
│  LLM 叙事文本区域                 │
│  （打字机逐字浮现效果）            │
│                                  │
│  ───── 发光分割线 ─────           │
│                                  │
│  [展开建议选项 ▼]（隐藏按钮）     │
│  点击展开 → 2~4 个建议选项卡片    │
│                                  │
│  ┌──────────────────────────┐    │
│  │ 在此输入你的行动……       │    │
│  └──────────────────────────┘    │
└──────────────────────────────────┘
```

- LLM 文本：打字机逐字浮现，文本区有微弱的边缘光晕
- 分割线：渐变色发光横线（灵火蓝 → 暖金 → 透明），粒子沿线流动
- 建议选项按钮：默认收起，点击展开 2-4 个发光选项卡片，点击填入输入框
- 输入框：placeholder 有呼吸光效，回车提交
- 当触发决斗时：画面过渡推入全屏对战舞台

### 3.3 全屏对战舞台

完整还原《游戏王：大师决斗》场地布局：

**区域分布（我方视角在下，对手在上）：**

| 区域 | 位置 | 数量 |
|------|------|------|
| 怪兽区 | 中场横排 | 5 格 × 2（双方） |
| 魔法陷阱区 | 怪兽区后方 | 5 格 × 2（双方） |
| 额外怪兽区 | 中场左右 | 2 格（共享） |
| 场地魔法区 | 魔法陷阱区外侧 | 1 格 × 2 |
| 卡组 | 右下 | 1 |
| 额外卡组 | 右下 | 1 |
| 墓地 | 侧边 | 1 × 2 |
| 除外区 | 侧边 | 1 × 2 |
| 手牌 | 底部 | 扇形排列 |

**显示信息：**
- 双方名称、LP（生命值）、手牌数量
- 怪兽卡：名称、ATK/DEF、表示形式（攻击/守备）
- SET 卡：神秘覆盖层 + 旋转星光粒子
- 场地魔法激活后：半场氛围色 + 粒子效果
- 墓地发光强度与卡牌数量正相关

**Ori 风格化处理：**
- 我方半场：暖金辉 + 灵火蓝色调
- 对手半场：暗紫 + 血红色调
- 卡牌入场：带拖尾粒子轨迹 + 弹跳微动效
- 怪兽立体投影感（CSS 3D 微倾斜 + 底部光环）

**对战核心阶段：**
- 抽牌阶段 → 主要阶段1 → 战斗阶段 → 主要阶段2 → 结束阶段
- 连锁机制：卡牌效果可互相响应
- 怪兽表示形式切换：攻击表示 / 守备表示
- 召唤方式：通常召唤、特殊召唤、融合召唤、超量召唤

### 3.4 卡组编辑界面

三个子标签：**卡组列表** / **编辑模式** / **卡牌图鉴**

**卡组列表：**
- 多个卡组槽位卡片，显示名称、卡牌数量（主/额外）、卡组类型缩略统计

**编辑模式：**
- 上半部分：卡牌库（可搜索、属性筛选、翻页）
- 下半部分：当前卡组网格
- 拖动添加/移除卡牌（弹性动画 + 拖拽阴影）
- 数量限制提示（主卡组 ≤60，额外卡组 ≤15，同名卡 ≤3）
- 右键卡牌查看详细面板（悬浮模态框）

**卡牌图鉴：**
- 所有已获得卡牌的图鉴视图
- 按属性/类型筛选，未获得的显示为暗色剪影

### 3.5 伙伴界面

- 2-4 位伙伴以纵向卡片列表展示
- 每张卡片：立绘区（左侧）+ 信息区（右侧）
- 信息区：名称、好感度星级、当前所在地、状态标签
- 状态标签颜色：休整=蓝翠、探索=暖金、紧张=暗红
- 好感度变化时：卡片划过流光动画
- 未解锁伙伴：半透明剪影 + "???"
- 底部提示"在未来旅程中结识新的伙伴……"

### 3.6 地图界面

- **底图：** 手绘风格大地图，包含森林、湖泊、山脉、城镇/村落/古城等自然与人工地形
- **节点：** 圆形发光节点代表事件/地点，路径线连接
- **节点状态：**
  - 可前往：呼吸脉冲光效（扩散光环）
  - 已完成：暖金色暗光
  - 未解锁：灰色半透明
- **交互：**
  - 拖拽平移 + 滚轮缩放（有限范围）
  - 悬停节点浮现手绘缩略图 + 名称卡片
  - 点击可前往节点触发事件
  - 鼠标移动时背景轻微视差偏移
- **底部状态栏：** 当前区域名称、可前往数量、探索进度（X/Y）

### 3.7 背包界面

- 网格布局（5列自适应），分类标签过滤
- 分类：[全部] [消耗品] [素材] [关键物品] [卡包]
- 物品图标：稀有度颜色光框（灰/蓝/紫/金）
- 悬停放大 + 稀有度粒子飘散
- 点击物品：底部详情面板（名称、稀有度星级、效果描述、使用/丢弃按钮）
- 新物品提示：侧边栏背包图标金色圆点角标
- 右上角显示灵辉货币余额

## 4. 通知系统

### 4.1 四种通知类型

| 类型 | 颜色 | 用途 |
|------|------|------|
| 普通提示 | 蓝辉 | 获得物品、卡牌入账、进度更新 |
| 成功 | 绿辉 | 操作确认，1.5s 自动消失 |
| 警告 | 橙辉 | 血量低、背包满、卡组未达标 |
| 错误 | 红辉 | 操作失败、数量超限 |

### 4.2 行为

- 从右上角滑入堆叠排列
- 每条有进度条倒计时
- 悬停暂停倒计时，点击手动关闭
- 入场：slide-in-right + fade-in
- 出场：slide-out-right + fade-out

## 5. 动效系统

### 5.1 全局微交互

- 悬停按钮：轻微缩放（1.03x）+ 外发光增强 + 过渡 200ms
- 标签切换：内容区淡入淡出 250ms
- 侧边栏图标：悬浮展开标签文字（150ms ease-out）
- 粒子环境：全局低密度浮动粒子（CSS animation）

### 5.2 战斗动画

- 卡牌入场：从手牌区飞出 + 拖尾粒子 + 弹跳落地
- 攻击动画：卡牌震动 → 冲击波扩散
- LP 变化：数字抖动 + 颜色闪烁
- 墓地送葬：卡牌翻转缩小飞向墓地
- SET 卡：旋转星光粒子环绕

### 5.3 性能策略

- 使用 CSS `transform` / `opacity`（GPU 加速）做动效
- 粒子系统用 CSS `@property` + 关键帧
- 超过 50 张卡牌时虚拟化渲染
- 非当前标签页懒初始化

## 8. 约束与范围

### 8.1 范围内（实现）

- 所有 7 个界面的完整 HTML/CSS/JS 实现
- 每个界面至少展示具有具体内容的设计（非空占位符）
- 全中文化 UI（LOGO 和纯视觉元素除外）
- 现代排版、微交互动画、粒子系统
- 内部通知系统
- 语义化 HTML5、唯一交互元素 ID
- localStorage 数据持久化
- 标题界面 → 主应用完整流程

### 8.2 范围外（不做）

- 后端 API / 数据库
- LLM 集成（使用模拟对话数据）
- 真实网络对战
- 音频系统（仅预留音量滑块 UI）
- 图片/立绘资源（使用 CSS 生成的视觉占位）
- 移动端完整适配（保留响应式基础，优先桌面体验）
