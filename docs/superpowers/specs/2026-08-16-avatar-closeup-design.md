# 光之回响设计：头像浮层 + 全屏特写交互重构

**日期**：2026-08-16
**状态**：已获用户逐节确认
**范围**：场景内角色呈现方式改为头像浮层，点击头像进入全屏脸部特写对话视图；废除立绘合成层与「提出决斗」按钮；表情差分推后

## 1. 背景与目标

场景交互式重构（2026-08-16-scene-interactive-refactor）落地后，立绘合成效果不佳（画风不统一、阴影不自然）。用户在方向 A/B/C 中选定方向 A（生成式 CG），随后进一步推翻合成思路，提出新交互模型：

- 角色**不**画进场景 CG，也不以全身立绘合成进画面
- 角色在场景中以**站位浮层头像**呈现，点击头像进入**全屏脸部特写** + 对话输入框
- 表情差分推后，本轮只做中性脸部特写

## 2. 已确认的需求决策

| 决策项 | 结论 |
|---|---|
| 角色场景呈现 | 站位浮层头像（圆形裁剪 + 名字标签，悬停放大），锚点复用 `characterSpots` |
| 头像点击行为 | 进入全屏脸部特写视图（`closeup-open` 事件契约沿用，下游零改动） |
| 特写形态 | 全屏切换（非叠层）：脸部特写图居中，名字/对话/输入框在底部 |
| 提出决斗按钮 | **删除**。决斗改为纯输入框路径（玩家输入 → AI 返回对战卡片 → `_launchBattle`） |
| 表情差分 | **本轮不做**（推后）。`emotionFile` 协议与 `closeup` 状态字段保留 |
| 脸部特写图 | **用户自己在 ComfyUI 生成**（6 张中性），生成完交给我集成 |
| 场景 CG（角色画进场景） | **不做**。16 张现有背景图继续使用 |
| fullbody 图 | 运行时不再引用（唯一用途 scene.js:55 立绘合成层退役）；**文件保留在磁盘**作外观定稿参考；`CHARACTERS.fullbody` 字段删除，新增 `portrait` 字段 |
| 降级链 | 特写图缺失 → `assets/characters/<id>/fullbody.png` 撑满兜底（路径按约定硬编码，不依赖数据字段）→ 皆无则「立绘缺失」文案 |

## 3. 交互模型总览

```
┌──────────────────────────────────────┐
│  [← 卧室]              [→ 家门]      │  ← 方向出口（现有）
│                                      │
│        场景背景图（16 张现有）          │
│                                      │
│              ⭕白月         ✦ 沙发     │  ← 头像浮层（新）+ 物件热点（现有）
│              （名字标签）              │
│   ⭕塞壬                              │
│                                      │
│  [↓ 出门]       「温暖的客厅，白月和     │  ← 旁白字幕（现有）
│                 塞壬的日常据点。」      │
└──────────────────────────────────────┘
         │ 点击 ⭕白月
         ▼
┌──────────────────────────────────────┐
│                                      │
│        ▓▓▓▓▓▓▓▓▓▓▓▓▓▓               │
│        ▓ 脸部特写图  ▓               │  ← 全屏特写（新视图）
│        ▓▓▓▓▓▓▓▓▓▓▓▓▓▓               │
│                                      │
│  ── 白月 ────────────────────── ✕    │  ← 关闭回场景
│  “今天也一起打牌吧？”                │  ← 对话引擎（现有，挂载点不变）
│  [输入框]                            │
└──────────────────────────────────────┘
```

**核心流转**：场景视图 ⇄ 特写视图两个全屏状态互相切换（不再是叠层）；对话引擎、AI 链路原样挂在特写视图里，容器从 overlay 换成全屏层。

## 4. 数据模型变更（`js/scenes-data.js`）

| 项 | 变更 |
|---|---|
| `CHARACTERS` | 删除 `fullbody` 字段，新增 `portrait: 'assets/characters/<id>/neutral.png'`（头像与特写共用） |
| `emotionFile(charId, emotion)` | 协议保留不动（未来表情差分仍走 `<id>/<emotion>.png`）；本轮只有 `neutral.png` 有图 |
| `characterSpots` | 复用为头像锚点：头像圆心 = `(spot.x, spot.y − 0.12)`（站位上抬到头部位置），`spot.scale` 决定头像大小 |
| `scene.characters` | 不变（场景角色阵容） |
| `closeup` 状态字段 | 不变（active / characterId / emotion） |

## 5. 模块改动清单

| 模块 | 动作 |
|---|---|
| `js/scene.js` | `_renderCharacters` 重写为 `_renderAvatars`：全身 sprite 层退役，改圆形头像按钮（CSS 裁剪 `portrait` 图 + 名字标签 + 悬停放大）；点击沿用 `closeup-open` CustomEvent 契约 |
| `js/closeup.js` | 重写为全屏视图：不透明全屏层 + 特写图居中 + 底部名字/对话/输入框；删除「提出决斗」按钮；对外 API 不变（`open / close / setEmotion / getDialogEl`） |
| `js/app.js` | 删除 `closeup-duel` 监听（app.js:110-112） |
| `js/event.js` | 删除死代码 `triggerDuelByButton`（event.js:675）；`_launchBattle` 及输入框→AI→对战卡片链路保留 |
| `css/scene.css` | 头像浮层样式（替换 sprite 样式） |
| `css/closeup.css` | 全屏特写布局样式 |
| `js/scenes-data.js` | 见第 4 节 |

**不改动**：物件热点、方向出口、旁白字幕、对话引擎挂载点（`#closeup-dialog`）、存档体系、AI/bridge 链路。

## 6. 素材规格与集成流程

- **6 张脸部特写**（用户 ComfyUI 生成）：1216×832 横图（与场景同宽高比），脸部居中占画面主体，中性表情，纯色/简洁背景，沿用 Anima Base 画风与已定稿角色外观
- **集成**：用户提供文件路径 → 落盘 `assets/characters/<id>/neutral.png` + 同步复制桌面审查目录 → 跑校验脚本 + 游戏真机确认
- **图未到位期间**：游戏照常运行，走降级链

## 7. 错误处理与降级

| 场景 | 处理 |
|---|---|
| 头像图缺失/加载失败 | 灰色圆形占位 + 名字标签仍显示（沿用 `sprite-missing` 模式） |
| 特写图缺失 | 降级用 `assets/characters/<id>/fullbody.png`（路径按约定硬编码）撑满特写区 |
| 两者皆无 | 「立绘缺失」文案占位 |
| 特写打开时角色 id 未知 | `open()` 静默返回（现有守卫保留） |
| 快速连点头像 | 特写以最后一次点击为准（现有 `open` 覆盖语义，不加锁） |

## 8. 校验脚本

`scripts/validate-scenes.mjs` 小改：
- 新增 `portrait` 路径形状检查（`assets/characters/<id>/neutral.png`）
- **不做文件存在性检查**（用户图未到位前不阻塞校验）
- `emotionFile` 协议检查保留不动

## 9. 测试与验收

- 场景漫游回归：16 节点出口连通、物件热点、旁白字幕
- 头像层：8 个有角色场景的头像锚点位置/大小正确；点击 → 全屏特写；关闭 → 回场景且场景状态不丢
- 对话链路：输入框 → bridge → narrative 渲染（本机无 API key，用现有 `smoke-bridge-emotion.py` 验证协议路径；真实 LLM 待配 key 后补验，属 Task 12 遗留）
- 决斗：输入框触发对战卡片 → `_launchBattle`（真机 YGOPro 回归同属 Task 12 遗留）
- 存档：特写打开状态下保存/读档，恢复后 closeup 状态一致
- 移动端：全屏特写与头像浮层小屏布局

## 10. 明确不做（本轮）

- 表情差分（8 情绪 × 6 角色）
- 角色画进场景的 CG 图
- 全身立绘合成层（退役删除）
- 边缘角色按钮方案（被头像浮层取代）
- 角色时间表/位置覆盖（未来增强，与本设计无关）
